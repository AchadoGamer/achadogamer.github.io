Política de Privacidade

Última atualização: 2 de outubro de 2026 · English version below

Esta política vale para o site Achado Gamer e para o Achado Gamer Publisher, a ferramenta interna do canal Achado Gamer que usa os Serviços de API do YouTube.

Serviços de API do YouTube

O Achado Gamer Publisher usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Os dados tratados pelo Google seguem a Política de Privacidade do Google (http://www.google.com/policies/privacy).

Quem usa a ferramenta

A ferramenta não é oferecida ao público. Ela é usada somente pelo dono do canal Achado Gamer, no próprio computador, para gerenciar o próprio canal.

Quais dados acessamos e para quê

  • Dados do canal (nome, ID e estatísticas públicas): para confirmar que o login é do canal Achado Gamer.
  • Vídeos do canal (título, descrição, tags, status de privacidade e agendamento): para enviar vídeos novos, agendar a publicação e atualizar descrições e links.

Não acessamos dados de outros canais, de espectadores, comentários nem mensagens. Não usamos os dados para publicidade nem criamos perfis de usuários.

Armazenamento e compartilhamento

O token de acesso do Google fica guardado apenas no computador do dono do canal. Nenhum dado obtido pela API é vendido, compartilhado com terceiros ou enviado para servidores nossos. Dados obtidos pela API não são guardados por mais de 30 dias, exceto o próprio token de autorização.

Cookies

Este site não usa cookies nem ferramentas de rastreamento próprias. Os vídeos do portfólio ficam hospedados no próprio site; só os botões levam ao YouTube, que segue a política do Google. Os links de afiliado levam à Amazon, que tem a própria política de privacidade.

Como revogar o acesso e excluir dados

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google: https://security.google.com/settings/security/permissions. Ao revogar, o token deixa de funcionar e é apagado do computador. Pedidos de exclusão podem ser enviados para o e-mail abaixo e são atendidos em até 7 dias.

Privacy Policy (English)

Last updated: October 2, 2026

This policy covers the Achado Gamer website and Achado Gamer Publisher, an internal tool of the Achado Gamer YouTube channel that uses YouTube API Services.

YouTube API Services

Achado Gamer Publisher uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy (http://www.google.com/policies/privacy).

Who uses it

The tool is not offered to the public. It is used only by the owner of the Achado Gamer channel, on their own computer, to manage their own channel.

Data accessed and why

  • Channel data (name, ID, public statistics): to confirm the signed-in account is the Achado Gamer channel.
  • Channel videos (title, description, tags, privacy status, scheduled time): to upload new videos, schedule publishing and update descriptions and links.

We do not access other channels, viewers' data, comments or messages. Data is not used for advertising or profiling.

Storage and sharing

The Google access token is stored only on the channel owner's computer. No API data is sold, shared with third parties or sent to our servers. API data is not stored for more than 30 days, except the authorization token itself.

Cookies

This website does not use its own cookies or tracking tools. The portfolio videos are hosted on this website itself; only the buttons lead to YouTube, which follows Google's policy. Affiliate links lead to Amazon, which has its own privacy policy.

Revoking access and deleting data

Access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions. Once revoked, the token stops working and is deleted from the computer. Deletion requests can be sent to the email below and are handled within 7 days.
